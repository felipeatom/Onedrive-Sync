# Onedrive-Sync

Onedrive-Sync is a Linux desktop client for Microsoft OneDrive built with Python, PyQt6, MSAL, Microsoft Graph, SQLite, and watchdog.

## Usage

```bash
onedrive-sync
```

Headless mode:

```bash
onedrive-sync --no-gui
```

Show version:

```bash
onedrive-sync --version
```

## Install

```bash
./install.sh
```
